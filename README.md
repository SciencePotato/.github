# SciencePotato Community Defaults

This repository provides shared contribution, security, issue, and pull request guidance for SciencePotato repositories that do not define their own versions.

Repository-specific files take precedence when a project needs different commands, policies, or templates.

## Included defaults

- Responsible security reporting guidance
- Contribution and conduct expectations
- Bug and feature request forms
- Pull request validation checklist

These defaults are intentionally lightweight. Project setup, architecture, testing, and deployment instructions belong in each repository.
