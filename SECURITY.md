# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use the repository's **Security** tab to submit a private vulnerability report or draft security advisory. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

Reports will be reviewed on a best-effort basis. Public disclosure should wait until the issue has been investigated and a fix or mitigation is available.

## Supported versions

Unless a repository documents a different policy, security fixes target the current default branch. Historical, archived, educational, and demonstration repositories may not receive security updates.
