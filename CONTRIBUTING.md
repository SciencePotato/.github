# Contributing

Thanks for taking the time to improve this project.

## Before making a change

1. Read the repository README and any local contribution or agent instructions.
2. Check existing issues and pull requests to avoid duplicate work.
3. For a substantial behavior or architecture change, open an issue before implementation.

## Pull requests

- Keep the change focused and avoid unrelated refactoring.
- Preserve the repository's existing style and public interfaces unless the change requires otherwise.
- Add or update tests when behavior changes.
- Run the documented lint, type-check, test, and build commands that apply.
- Explain what changed, why it changed, and how it was validated.
- Do not commit secrets, generated credentials, local environment files, or unrelated dependency changes.

Repository-specific guidance overrides this shared document.
